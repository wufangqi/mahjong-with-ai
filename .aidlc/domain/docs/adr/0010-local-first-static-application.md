# 本地优先的静态应用

应用以 GitHub Pages 为默认发布目标，也能部署到任意静态服务器；构建支持非根路径。除可选外接 AI 外，生产构建不访问网络。不做 PWA、账号、登录或云同步。音量、主题和显示设置保存在 localStorage，当前场快照与动作日志保存在 IndexedDB，并提供清除本地数据。

外接 AI 的代理地址和模型名可以持久化，访问令牌只存在当前浏览器会话，不进入 localStorage、IndexedDB、日志或导出文件。代理必须允许站点来源的 CORS；本机开发可以使用 `http://localhost`，生产只接受 HTTPS。由于 GitHub Pages 无法为运行时任意代理生成精确 CSP，`connect-src` 允许同源和 HTTPS，应用代码只请求用户配置的唯一代理地址。

首发界面只使用简体中文，但用户文案集中管理。自动保留最近 20 场动作日志，当前存档另计；玩家可以导出或清空。项目没有固定日期与预算，以单人开发先完成可玩纵切版、再评估 MVP 1.0 为计划。

## Considered options

- PWA 与 Service Worker 离线缓存
- 账号、云存档和跨设备同步
- 在浏览器中长期保存外接 AI 令牌
