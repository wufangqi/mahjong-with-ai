# 当前状态是权威，事件用于通知和回放

纯 TypeScript 规则核心接收命令，返回新的权威状态与领域事件，不采用完整 Event Sourcing。存档保存带 `schemaVersion` 的状态快照，动作日志用于开发者回放和调试；旧快照只有在存在明确迁移器时才迁移，否则提示导出后重新开始。一炮多响由单个 `HandWon` 事件原子地携带全部赢家，避免第一家胡牌提前终止结算。

核心胡牌事件只含赢家、牌、点炮或自摸、手牌、副露、番型与番数，不含 `tier`、横幅或 `themeId`。表现层负责映射特效档与横幅，并从播放开始时的主题读取配色。规则算法放在有测试的 TypeScript `RuleSet` 中；JSON 只承载可校验的常量和展示配置，不承诺仅改 JSON 就能新增规则。

## Considered options

- 完整 Event Sourcing：每次加载都从事件重建状态
- 把特效档和主题写进规则核心的胡牌事件
- 用 JSON 表达整个规则状态机与番型算法
