# 外接 AI 是可选的对手决策来源

对局把对手决策隔在统一边界后面：内置 easy 对手是离线兜底，也可以接 OpenAI-compatible 服务。三家可分别选择来源，但共用代理和模型配置。外接 AI 只收到该座位的手牌、公开副露、牌河、剩余牌数、庄家、当前轮次和合法动作；不收到其他家的手牌、牌墙顺序或随机种子。首次启用前向玩家展示代理地址、发送字段和明确不发送的内容，确认后才启用。响应窗口内并行请求，非法、失败或 20 秒内没有返回就回退内置对手。事件记录保存洗牌种子和最终采用的动作，回放不重新调用 AI。浏览器不保存模型厂商的 API Key，云模型经用户自己的代理服务接入，因此不破坏离线可玩。产品不集成分析 SDK，也不上传牌局、性能或调试数据；日志只保存在本地并由用户主动导出。

## Considered options

- 浏览器直接保存模型厂商 API Key
- 只保留内置规则对手，不允许外接 AI
