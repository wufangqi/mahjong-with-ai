# 3D 麻将 · 胡牌特效 Demo

纯浏览器 Demo（Three.js r160），一张麻将桌 + 14 张 3D 手牌，三个按钮各播放一档胡牌特效。

## 运行

ES Module 不能用 `file://` 打开（浏览器会拦截），需要起一个静态服务器：

```bash
cd mahjong-win-demo
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

其他方式也可以：`npx serve .`，或者 VS Code 的 Live Server 插件。

- Three.js 已经放在本地 `vendor/three/` 下（约 1.4 MB），**完全离线可用**，不依赖 CDN。
- 如果想改用 CDN，把 `index.html` 里 importmap 的两个路径换成注释里的 jsDelivr 地址即可。
- 浏览器需要支持 WebGL2 和 importmap（Chrome / Edge / Firefox / Safari 16.4+ 都可以）。

## 操作

| 按钮 | 快捷键 | 手牌 | 特效 |
|---|---|---|---|
| 基础胡 | `1` | 平胡 | 手牌依次弹起、略微后仰；金色描边闪两次；牌面微亮；金白闪粉喷出；横幅「胡」（约 2.6 秒） |
| 大牌胡（如清一色） | `2` | 清一色万子 | 镜头先拉远；14 张牌沿弧线飞到桌中央围成旋转的圆环；冲天光柱 + 白色内核；桌面多圈金色涟漪；粒子绕光柱螺旋上升；镜头猛推近后回位，轻微震屏；横幅「清一色」（约 3.8 秒） |
| 顶级胡（如国士） | `3` | 国士无双 | 画面去饱和 + 暗角，牌在慢动作中浮起旋转、彩虹描边越来越亮；然后白闪 + 震屏，牌炸成约 5000 颗光粒，在空中盘旋聚合成一个巨大的「胡」字；成字瞬间强辉光（Bloom 峰值）+ 第二次震屏 + 冲击波火花 + 桌面涟漪；随后光粒向上飘散，牌依次弹回原位；横幅「国士无双」（约 4.6 秒） |

- 播放中再点任意按钮，会立即打断当前特效并从头重播。
- 右上角可以开关音效。音效用 WebAudio 实时合成，不需要音频文件。

## 文件结构

```
index.html   页面、UI 叠层、CSS 横幅动画、importmap
main.js      场景、牌桌、相机、后处理（UnrealBloomPass）、三种特效的时间轴
tiles.js     麻将牌：CanvasTexture 绘制牌面（萬/筒/索/字牌）+ 圆角立方体
fx.js        粒子池、光柱着色器、涟漪着色器、文字取点、缓动函数
audio.js     合成音效
vendor/      Three.js r160 本地副本（build + 用到的 examples/jsm 模块）
```

## 扩展思路

每个特效都是一个继承 `Effect` 的类，实现 `update(dt)`。新加一档牌型只需要写一个新类，然后在 `EFFECTS` 里注册、加个按钮。以后迁到 Unity 时，可以按同样的结构拆：`WinEvent(牌型) → 特效配置 → 播放`。

## 已知限制

- 牌面文字用的是系统字体（楷体 / 思源 / 微软雅黑等）。不同系统上「胡」字和牌面的字形会略有差别；如果系统没有中文字体，会显示成方块。
- 没有真实的麻将逻辑（摸牌、出牌、判胡），按钮只是直接触发特效。
- 顶级胡的 5000 颗粒子每帧在 CPU 上更新，低端手机上可能掉帧。可以在 `main.js` 里把 `this.N` 调小。
- 竖屏手机上整排手牌能放下，但看起来偏小。
